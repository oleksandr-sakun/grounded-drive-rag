# Security Policy (signed).pdf




## Information Security Policy



## Device requirements


All laptops must have full-disk encryption enabled and an automatic screen lock after 5 minutes 
of inactivity. Personal devices may not be used to access customer data.


## Passwords and MFA


Multi-factor authentication is mandatory on all company accounts. Hardware security keys are 
provided on request and are required for anyone with production access. Shared passwords are 
prohibited. Use the company password manager (1Password).


## Customer data


Customer data may only be stored in approved systems: the production database, the data 
warehouse, and the support desk. Exporting customer data to a personal machine, a 
spreadsheet, or a third-party AI tool is prohibited without written approval from the Security 
team.


## Incident reporting


Suspected security incidents must be reported in #security-incidents within 1 hour of discovery. 
There is no penalty for reporting something that turns out to be harmless.
